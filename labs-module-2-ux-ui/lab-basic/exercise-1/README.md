# Module 2 - Basic Laboratory - Exercise 1: UX/UI

Design of a **password generator** web app in Figma: low fidelity wireframes, a small design system and the high fidelity screens, for both desktop and mobile.

- [Design System](https://www.figma.com/design/MI5EkqFAwmNbpZcxHgLBiR/Lemoncode-LAB?node-id=1-2&t=f2v0JikLobE5qTy1-1)
- [High Fidelity (UI)](https://www.figma.com/design/MI5EkqFAwmNbpZcxHgLBiR/Lemoncode-LAB?node-id=1-3&t=f2v0JikLobE5qTy1-1)

## What is included

- **Low Fidelity**: desktop and mobile wireframes with the layout and hierarchy of the generator, the history and the footer.
- **Design System**
- **High Fidelity**: desktop (12-column grid) and mobile (4-column grid) screens built with Auto Layout and component instances, using only design system variables and styles.
